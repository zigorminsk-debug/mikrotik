Интерактивный стенд моделирования

Задайте исходную задачу — стенд рассчитает адресацию, сгенерирует конфигурацию RouterOS, проверит модель на ошибки и выдаст пошаговую инструкцию для реализации на реальном роутере.

🌐 Локальная сеть (LAN)
🛏️ Гостевая сеть
📶 Wi‑Fi
🔌 Интернет‑провайдеры
🔁 Резервный канал интернет
🔐 VPN (по необходимости)
🌍 Доступ во внутренние ресурсы из интернета (NAT)

Укажите внутренний IP и порт, которые должны быть открыты наружу, и через какого провайдера (или через всех).

🔌

Прямое подключение к MikroTik

Работа с реальным роутером RouterOS по API (порт 8728) или API-SSL (порт 8729): выполнение команд в консоли и применение конфигурации, сгенерированной интерактивным стендом.

🎯 Цель подключения

Выберите, куда отправлять команды: на настоящий MikroTik по API или на встроенный симулятор RouterOS (не требует сети и оборудования).

🔌 Сессия (реальный роутер)
Не подключено

API роутера должен быть включён (/ip service enable api, для SSL — api-ssl). Пароль передаётся только указанному роутеру и никуда больше.

🖥️ Сессия (виртуальный роутер)
Симулятор остановлен
🗺️ Карта сети — интерактивная схема устройства не выбраны

Симулятор ведёт модель конфигурации RouterOS в памяти браузера. Карта сети показывает топологию: кликните на устройство для выбора, затем примените конфигурацию на роутер.

🖥️ QEMU CHR — виртуальная машина RouterOS
Остановлена

Запускает полноценный RouterOS CHR в QEMU. Для работы нужен образ chr-xxx.qcow2 в каталоге данных приложения.
