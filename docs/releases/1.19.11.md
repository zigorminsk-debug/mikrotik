# MikroTik Guide 1.19.11

- В каждом разделе учебника появилась карточка «Проверить на стенде». Первые реальные сценарии подготовлены для первичной настройки, IP, Interfaces, Bridge, Routing и System; у разделов без сценария это прямо указано. Возможность проверки **всех** разделов ещё не реализована.
- Можно отметить функции поддерживаемого раздела. Статический и DHCP WAN на одном порту, VLAN без Firewall, гостевой DHCP без VLAN и DNS-запись без DNS-кэша блокируются с объяснением. Текущая учебная модель требует NAT; в этом сценарии NAT требует Firewall как политика безопасности. Недоступные Wi-Fi, VPN, PPPoE и прочие функции не отправляются в CHR.
- Переход создаёт отдельную учебную схему; для замены существующей нужно подтверждение. Модель запускается без настоящей RouterOS. В Windows поддержанные настройки можно затем отдельно применить к одноразовой изолированной CHR после согласия и проверки плана; Android и браузер пока только моделируют. Физический роутер не изменяется.
- Виртуальные клиенты, физические провайдеры и интернет не эмулируются. NTP синхронизация и работоспособность статического маршрута не проверяются. Открывается WebFig; автоматические снимки WinBox всех настроек пользовательской схемы пока не готовы.
- Постоянный ключ подписи APK находится в репозитории по требованию владельца и публичен. Он не доказывает авторство; устанавливайте приложение из доверенного источника.
