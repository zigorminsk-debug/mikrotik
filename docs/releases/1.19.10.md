# MikroTik Guide 1.19.10

Этот выпуск ускоряет будущие сборки и содержит исследования, **не новую готовую функцию автоснимков**.

- При релизном теге больше не должны запускаться все исследовательские workflows: они сохраняют запуск по изменениям в ветке и вручную. Полная сборка и тесты Windows/Android, проверка APK и проверка обновления остаются. Большой Windows-артефакт передаётся без повторного сжатия. Для релиза результаты профильных проверок в ветке по-прежнему обязательны.
- Исследован оригинальный WinBox 4.4 на одноразовой изолированной CHR: адресное управление без переключения фокуса открыло карточку существующего LAN-адреса с полями Address, Network и Interface. [CI 41299657462](https://github.com/zigorminsk-debug/mikrotik/actions/runs/41299657462), снимок и ограничения — `docs/lab-winbox-screenshots.md`. Это один фиксированный тест, не снимок пользовательской схемы. Нельзя считать его автоматизацией всех шагов.
- На Windows из результатов успешной проверки можно отдельно запустить настоящую CHR; открывается WebFig. Неподдерживаемые настройки блокируются, сеть требует отдельного согласия. Физический MikroTik не изменяется; клиенты и физические провайдеры не эмулируются. Android не запускает CHR.
- Автоматическое создание оригинальных снимков **всех настроек конкретной пользовательской схемы в WinBox ещё не реализовано**. Прямое подключение и передача схемы на физический роутер по MAC также ещё не реализованы.
- APK подписан постоянным ключом из репозитория по требованию владельца. Этот ключ публичен и не доказывает авторство. Устанавливайте приложение из доверенного источника.

Веточный [Build 41299959363](https://github.com/zigorminsk-debug/mikrotik/actions/runs/41299959363) и теговый [Build 41300427590](https://github.com/zigorminsk-debug/mikrotik/actions/runs/41300427590) прошли тесты, подписанную Android-сборку и сборку с проверкой установленного Windows EXE. На теге действительно запустились только Build и Android update, а не десятки исследований. Размеры файлов: APK 3 772 595 байт, EXE 1 136 591 771 байт. Браузер, системный установщик Android и физический телефон не проверялись.
