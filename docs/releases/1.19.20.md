# MikroTik Guide 1.19.20

- Начата перестройка учебника по меню WinBox 4. В разделе Interfaces добавлены 13 вкладок в порядке предоставленного снимка: от Interface до LTE. На вкладках раскрываются 54 описания назначения и настройки выбранных параметров. Перечень пока неполный, а доступность полей зависит от модели и версии RouterOS; другие разделы ещё не перестроены.
- В карточку лаборатории Interfaces добавлены гостевой VLAN и его DHCP как доступ к существующему учебному сценарию: проверка конфликта и подтверждение замены схемы сохранены. Клиентская машина и её трафик не эмулируются; остальные вкладки не стали автоматически поддерживаться лабораторией.
- Ссылки на Windows и Android остаются в сводках сборок GitHub Actions; файлы релиза представлены чистым APK и EXE.
- Автоматические снимки всех настроек произвольной пользовательской схемы в WinBox и безопасное применение к физическому MikroTik по MAC пока не реализованы.
- Ключ подписи APK публичен по требованию владельца и не доказывает авторство.
