# 1.19.32 — проверка связей виртуальных устройств

В Windows-лаборатории после запуска совместимой CHR с Linux-клиентами добавлена кнопка «Проверить все направления». Она последовательно использует настоящие ping из запущенных VM: между виртуальной CHR и клиентами, а также между самими клиентами. Для каждой пары требуется отдельное подтверждение Windows; отмена прекращает оставшиеся проверки. Текущий диалог или отправленный запрос кнопка остановки не прерывает. Результат каждого направления показывается отдельно; ноль ответов не доказывает отсутствие связи.

Выбор целей ограничен адресом CHR и адресами Linux VM при запуске, DNS и внешние адреса не используются. После изменения схемы или настроек внутри VM необходим перезапуск: адреса автоматически не обновляются. Локальные процессы могут внедрять пакеты в виртуальную сеть. В учебник добавлена последовательность действий и предупреждения; оригинальные снимки каждого действия ещё не готовы.

Физический MikroTik, принтеры, провайдеры, VPN между офисами и интернет клиентов этой кнопкой не проверяются; Android реальные VM не запускает. Автоматические оригинальные снимки всех настроек пользовательской схемы со стрелками и безопасное применение схемы по MAC пока не реализованы. Сброс требует отдельного явного подтверждения. APK подписывается постоянным ключом, опубликованным в репозитории по требованию владельца; он не подтверждает подлинность автора.
