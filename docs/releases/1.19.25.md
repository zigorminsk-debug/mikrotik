# 1.19.25 — реальные Linux-клиенты в изолированной лаборатории Windows

В Windows для поддерживаемой проверенной схемы можно отдельно запустить CHR и до четырёх одноразовых Linux VM для устройств ПК и сервер, подключённых напрямую или через простой коммутатор. Клиенты используют выбранные статические IPv4/24, шлюз и DNS либо DHCP, при этом DHCP на LAN должен быть включён для загрузки Linux. В списке ping появляются фактические адреса и источники запущенных VM. Можно отправить три реальных ICMP-запроса из CHR или Linux-клиента на одиночный IPv4 с отдельным подтверждением и увидеть число ответов. У CHR остаётся раздельное подтверждение DNS и ping; Linux-клиент DNS-имена пока не поддерживает; статический DNS записывается и сверяется, полученный по DHCP DNS также сверяется, но его доступность не проверяется. Модель сама пакеты не отправляет.

Неподдерживаемая схема блокируется, настройки не заменяются: пока нельзя запускать принтеры, гостевой VLAN, дополнительные сетевые карты, два роутера или VPN. Провайдер на схеме не является виртуальным узлом; в этом режиме внешний интернет отсутствует. Linux-сервер не содержит прикладных служб, а ПК не воспроизводит пользовательскую ОС. Ноль ответов может означать блокировку ICMP или иные проблемы, а не обязательно отключённое устройство; после изменения схемы нужно перезапустить VM. Ручные изменения WebFig не сверяются с моделью.

Официальный образ RouterOS скачивается после ознакомления с лицензией MikroTik. Образ CirrOS 0.6.3 загружается отдельно с GitHub проекта после предупреждения и согласия, проверяется по зафиксированному размеру и SHA-256 и не включается в установщик. Это образ для испытаний с публичным паролем и sudo без пароля; не храните личные данные. Сеть не подключена к физическому LAN или интернету, но другие процессы компьютера могут внедрять в неё пакеты. Полнота лицензий и исходников всех компонентов образа не проверена; ссылка на upstream приведена в диалоге и `docs/cirros-guest.md`. При закрытии CHR временные диски удаляются.

На Android реальный ping лаборатории не доступен. Автоматические оригинальные снимки всех настроек пользовательской схемы в WinBox, применение к физическому MikroTik по MAC, работающий VPN двух офисов и интернет с клиентов ещё не реализованы. В учебнике описаны шаги и ограничения; оригинальные снимки подтверждений и результата пока не добавлены. Сборка Windows включает QEMU, его исходники и лицензии; Android APK подписывается постоянным публичным ключом из репозитория по требованию владельца.
