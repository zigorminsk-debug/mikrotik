# MikroTik Guide 1.19.15

- Раздел System позволяет выбрать правила журнала тем system и interface совместно с именем и NTP. В карточках уточнено, какие базовые настройки заранее добавляются в сценарии Queues и Log. Существующая схема заменяется только после подтверждения.
- Совместимая схема запускается отдельно на виртуальной CHR в Windows после необходимых согласий. Правила журнала используют память: возникновение событий и их сохранность не проверяются. Также не проверяются доступность NTP и фактическая синхронизация времени. Журнал может содержать чувствительные данные; физический MikroTik не изменяется.
- Многие разделы и функции ещё не поддерживаются. Автоматические оригинальные снимки WinBox всех настроек конкретной пользовательской схемы не реализованы.
- Ключ подписи APK намеренно хранится в репозитории по требованию владельца, он публичен и не доказывает авторство. Устанавливайте только из доверенного источника.
