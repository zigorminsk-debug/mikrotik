# MikroTik Guide 1.19.18

- В GitHub Actions возвращена выгрузка Windows-установщика для каждой успешной сборки ветки и тега; ссылки на Windows и Android добавлены в сводки соответствующих заданий. Артефакты Actions скачиваются в ZIP и могут требовать вход в GitHub.
- В сводке теговой сборки показаны прямые ссылки на EXE и чистый APK релиза. Они становятся доступными после проверки и публикации черновика.
- Автоматические оригинальные снимки WinBox всех настроек пользовательской схемы и безопасное применение к физическому MikroTik по MAC всё ещё разрабатываются. Поиск соседей не выполняет подключение или запись.
- Ключ подписи APK публично хранится в репозитории по требованию владельца и не доказывает авторство; устанавливайте приложение только из доверенного источника.
