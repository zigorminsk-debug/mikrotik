# 1.19.30 — учебные снимки WinBox со стрелками

В разделе IP учебника добавлен отдельный пример IP → Addresses: пять кадров с красными стрелками и пояснениями показывают расположение New, строки LAN-адреса, полей Address и Interface и кнопки OK. Основа — оригинальные снимки Windows WinBox 4.4 и одноразовой CHR 7.23.8 из CI, визуально проверенные; стрелки добавлены после съёмки. Карточка показывает существующий учебный адрес, а не пустую форму New. Фактическое нажатие или сохранение на этих кадрах не показано. Адреса учебные, их нельзя без проверки переносить в свою сеть; служебный адрес ether6 относится к CI.

Это **статические примеры учебника**, не снимки вашей схемы. Автоматическое создание оригинальных снимков всех настроек конкретной схемы и стрелок для её инструкции ещё не реализовано. В CI исследуются две карточки адресов; автоматическая проверка WAN-интерфейса пока не прошла и не включена в приложение. Пользовательские VPN между офисами, принтеры, интернет клиентов и безопасное применение на физический MikroTik по MAC пока не готовы. Отдельное подтверждение сброса потребуется до любого его выполнения.

В Windows доступны ограниченная изолированная CHR и до четырёх CirrOS VM после отдельных согласий; их публичные учётные данные и возможность вмешательства локальных процессов требуют осторожности. Android реальные VM не запускает. APK подписывается постоянным публичным ключом, находящимся в репозитории по требованию владельца; это не защита подлинности автора.
