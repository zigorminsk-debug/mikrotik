# MikroTik Guide 1.19.19

- В исследовательском CI проверен реальный WinBox на одноразовой CHR для двух примеров схемы, включая изменённый в интерфейсе LAN-адрес. Адрес, сеть и интерфейс сверены на карточке с помощью Tesseract; адрес и сеть дополнительно сверены Windows OCR. Кадры визуально проверены. Это не пользовательская функция и не полная проверка всех настроек.
- Ссылки на Windows и Android остаются в сводках сборок GitHub Actions; артефакты Actions представлены ZIP-архивами и могут требовать входа. Чистый APK и установщик EXE публикуются отдельно в релизе.
- Автоматические снимки WinBox всех настроек произвольной пользовательской схемы и безопасное применение конфигурации к физическому MikroTik по MAC **не реализованы**. Сброс устройства без отдельного подтверждения не допускается.
- Ключ подписи APK находится в открытом репозитории по требованию владельца и не подтверждает авторство; устанавливайте приложение только из доверенного источника.
