# MikroTik Guide 1.19.21

- Во всех 13 вкладках Interfaces добавлены практические разделы: где применяется функция, последовательность действий, проверка результата, риски и доступность в лаборатории. Каждый из 59 описанных параметров и связанных понятий дополнен примером применения.
- Дополнены выбранные поля VLAN: ARP, ARP Timeout, MVRP, L3 HW Offloading и Enabled. Возможности зависят от версии RouterOS и оборудования; список параметров ещё не полный.
- Практические тексты работают без интернета; ссылки на официальные материалы требуют сеть. Новые оригинальные снимки WinBox для каждого действия пока отсутствуют и отмечены в учебнике.
- Новые практические примеры не добавляют возможности виртуальной лаборатории и не меняют физический роутер. Произвольные снимки схемы WinBox и применение к устройству по MAC пока не реализованы.
- Windows и Android доступны в сводках GitHub Actions; в релизе публикуются отдельные EXE и чистый APK. Ключ подписи APK публичен по требованию владельца и не доказывает авторство.
