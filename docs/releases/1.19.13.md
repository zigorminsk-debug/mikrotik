# MikroTik Guide 1.19.13

- В разделе Queues добавлен сценарий «Проверить на стенде»: Simple Queue для учебного ПК со статическим адресом 192.168.88.10/24 и симметричным пределом 10 Мбит/с. Queue Tree пока не поддерживается. Можно изменить IPv4 клиента в основной LAN вне DHCP-пула и целый предел от 1 до 1000 Мбит/с. Текущая схема заменяется только после подтверждения.
- В Windows поддерживаемая схема запускается на виртуальной CHR после отдельных согласий. ПК не запускается как VM: приложение проверяет наличие записи и её параметры, но не трафик и реальную скорость. FastTrack может обходить очередь; используйте пример только для обучения. Применение к физическому MikroTik пока не реализовано.
- [Windows CHR CI 41305654332](https://github.com/zigorminsk-debug/mikrotik/actions/runs/41305654332) применил сценарий из учебника к одноразовой изолированной CHR и сверил очередь через REST; [CI 41305654409](https://github.com/zigorminsk-debug/mikrotik/actions/runs/41305654409) снял карточку Windows-приложения без запуска CHR. Пройден теговый [Build 41306675688](https://github.com/zigorminsk-debug/mikrotik/actions/runs/41306675688), включая проверку подписи и Windows smoke-тест. Сам клиент, измерение скорости и установленный EXE по этому сценарию не проверялись.
- [Android update 41306675684](https://github.com/zigorminsk-debug/mikrotik/actions/runs/41306675684) проверил обновление 1.19.12 → 1.19.13 через adb в эмуляторе; физический телефон, браузер и системный установщик не проверены.
- Многие разделы и функции пока не поддержаны. Автоматические оригинальные снимки WinBox всех настроек конкретной пользовательской схемы не реализованы; CI-исследования их не заменяют.
- Ключ подписи APK намеренно хранится в репозитории по требованию владельца, он публичен и не доказывает авторство. Устанавливайте только из доверенного источника.
