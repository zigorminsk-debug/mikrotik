# MikroTik Guide 1.19.12

- В разделе IP учебника в «Проверить на стенде» добавлен выбор «NAT: доступ извне к учебному серверу». Сценарий создаёт сервер с учебным статическим адресом 192.168.88.20/24 и проект правил TCP 8443 → 443; при создании совместимой виртуальной CHR дополнительно проверяются правила dstnat и forward. Firewall обязателен; без него выбор блокируется с объяснением.
- Открытие сервиса наружу требует отдельной оценки безопасности. Учебный сервер не запускается как VM; в изолированной CHR порт Windows-хоста не пробрасывается, физический провайдер, публичный IP и доступ из интернета не проверяются. Подключение к физическому MikroTik и применение настроек не реализованы.
- Выбор проверяет комбинации до замены схемы и требует подтверждение для замены прежней. Windows может отдельно запустить поддержанную схему на виртуальной CHR с лицензией и согласиями; Android и браузер показывают только модель. Некоторые разделы всё ещё не поддерживаются.
- Автоматические оригинальные снимки WinBox всех настроек конкретной схемы ещё не реализованы; статические иллюстрации и эксперименты CI не заменяют их.
- Ключ подписи APK намеренно хранится в репозитории по требованию владельца, он публичен и не доказывает авторство. Устанавливайте только из доверенного источника.
