# MikroTik Guide 1.19.9

- После успешной проверки схемы в Windows можно открыть настоящую виртуальную CHR прямо из результатов. Запускается проверенная копия состояния; после изменения схемы требуется новая проверка. Приложение повторно проверяет поддерживаемость и запрашивает необходимые согласия. Физический роутер не затрагивается.
- Открывается WebFig. Автоматические оригинальные снимки всех настроек конкретной схемы в WinBox **ещё не реализованы**. Исследование ведётся отдельно; статические примеры не заменяют эту функцию. На Android виртуальная CHR пока недоступна.
- Виртуальные клиенты и физические провайдеры не эмулируются; изолированный DHCP WAN не доказывает интернет или маршрут по умолчанию. Ограниченный интернет-режим двух WAN требует отдельного согласия при каждом запуске и использует сеть Windows.
- Ускорена передача сборочных артефактов: веточная сборка по-прежнему собирает и проверяет EXE, но не загружает большой установщик без релизного тега; теговый установщик передаётся без повторного сжатия.
- APK подписан постоянным ключом из репозитория по требованию владельца. Этот ключ публичен и не доказывает авторство. Устанавливайте приложение из доверенного источника.
