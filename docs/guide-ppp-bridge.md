# Учебник PPP и Bridge

В WinBox 4.4 для Linux на одноразовой CHR 7.23.8 визуально проверены два оригинальных снимка ([CI 41394995185](https://github.com/zigorminsk-debug/mikrotik/actions/runs/41394995185)). Первый показывает список PPP → Interface, второй — Bridge → Bridge; в меню на снимках Bridge находится перед PPP. Снимки показывают не рабочую PPP-сессию и не проверку VLAN или действий пользователя.

Пока описаны только выбранные вкладки в видимом порядке: PPP — Interface (частично PPPoE Client), PPPoE Servers, Secrets, Profiles, Active Connections; Bridge — Bridge, Ports, VLANs, Hosts. В WinBox видны и другие вкладки: OVPN Servers, L2TP Ethernet, L2TP Secrets, MSTIs, Port MST Overrides, Filters, NAT, MDB. Описания остальных вкладок и всех полей, снимки каждого действия, а также реальная проверка всего этого функционала пока не готовы. Кнопка стенда ограничена поддерживаемыми учебными сценариями; PPPoE/VPN заблокированы.

Источники: [PPP AAA](https://manual.mikrotik.com/docs/authentication-authorization-accounting/ppp-aaa/), [PPPoE](https://manual.mikrotik.com/docs/virtual-private-networks/pppoe/), [PPP client](https://manual.mikrotik.com/docs/cli-reference/interface/pppoe-client/), [PPPoE server](https://manual.mikrotik.com/docs/cli-reference/interface/pppoe-server/server/), [Bridge](https://manual.mikrotik.com/docs/bridging-and-switching/), [bridge port](https://manual.mikrotik.com/docs/cli-reference/interface/bridge/port/), [bridge vlan](https://manual.mikrotik.com/docs/cli-reference/interface/bridge/vlan/), [bridge host](https://manual.mikrotik.com/docs/cli-reference/interface/bridge/host/). Справочники CLI по текущей версии могут отличаться от CHR 7.23.8. Перед применением сверяйте свою версию, модель и конфигурацию. Не раскрывайте PPP-пароли; для изменения мостов и VLAN подготовьте резервный доступ и план отката.
